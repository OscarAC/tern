# Tern Tern is a note format for studying: markdown's ease, LaTeX's structure, and the full power of the web, in one plain `.html` file. This page is a Tern note. Every example below is followed by its real output, rendered by the same script that renders the page. :aside[View this page's source to see the whole note. It is plain text under one script tag.] ::toc ## Getting started 1. Put `tern.js` somewhere your notes can reach. 2. Create an `.html` file whose first line loads it, with a path relative to the note. 3. Write below that line and open the file in a browser. ```html # My first note Some **bold** text and some math: $e^{i\pi} + 1 = 0$. ``` There is no build step. Notes work when opened straight from disk. :::warning The script tag must be a plain one. `async`, `defer` and `type="module"` all break it, and Tern logs an error to the console if it is loaded that way. ::: Two optional attributes go on the script tag: | Attribute | Effect | |---|---| | `data-katex="path"` | Load KaTeX from this folder instead of the CDN. Point it at a local copy of KaTeX's `dist` folder to work offline. | | `data-raw` | Show the note's source instead of rendering it. Useful for debugging. | Math needs KaTeX, which is fetched from the jsDelivr CDN by default. Without a network connection and without `data-katex`, math is shown as TeX source. ## Markdown Tern supports the markdown you already know. ````demo #### A small heading Text can be **bold**, *italic*, ~~struck~~ or ==highlighted==, and can hold `inline code`, a [link](https://katex.org "KaTeX") or an autolink like . - Bullets use `-`, `*` or `+` - Indent to nest: 1. numbered items use `1.` or `1)` 2. and can sit inside bullets - [x] task lists work - [ ] with `[ ]` and `[x]` > A blockquote. ```python total = sum(xs) # fenced code, with an optional language ``` | Space | Dim | |:-------|------:| | $\mathbb{R}^n$ | $n$ | | $P_k$ | $k+1$ | ```` | Element | Syntax | |---|---| | Headings | `# Title` through `###### Title` | | Bold | `**text**` or `__text__` | | Italic | `*text*` or `_text_` | | Strikethrough | `~~text~~` | | Highlight | `==text==` | | Inline code | `` `code` `` | | Link | `[text](url)` or `[text](url "title")` | | Image | `![alt](url)` | | Autolink | `` | | Line break | two trailing spaces, or a trailing `\` | | Horizontal rule | `---`, `***` or `___` | | Escape | `\*` shows a literal `*` | A blank line between list items makes the list loose: each item becomes a paragraph. In tables, colons in the delimiter row set alignment. Pipes inside math or code spans are safe, so `$|x|$` works in a cell. Use `\|` for a literal pipe elsewhere. Characters that normally need care in HTML need none here: a < b, AT&T and x && y can be typed as they are. HTML entities such as ` ` still work. ### Differences from standard markdown - **No indented code blocks.** Indentation never creates code; only fences do. This lets you indent freely inside blocks. - **No underlined (setext) headings**, reference-style links or footnotes. Use `#` headings, inline links and margin notes. - **Code is not syntax-highlighted.** A fenced block gets a `language-x` class, so you can add a highlighter yourself. ## Math ````demo Inline math sits in the text: $a^2 + b^2 = c^2$, and $a < b$ needs no escaping. $$ \begin{aligned} (a + b)^2 &= a^2 + 2ab + b^2 \\ &\ge 4ab \end{aligned} $$ $$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$ #eq-gauss Equation @eq-gauss is numbered because it has a label. ```` | Form | Syntax | |---|---| | Inline | `$a < b$` | | Display | `$$ ... $$` on its own line or lines | | Numbered display | `$$ ... $$ #label` | Inline math follows Pandoc's rule: the opening `$` must be followed by a non-space, and the closing `$` must follow a non-space and not be followed by a digit. This means a sentence like "costs $5 and $10" is left alone. Write `\$` for a literal dollar sign when in doubt. ### Macros Define TeX macros once per note in a `:::macros` block. They apply to all math in the note. ````demo :::macros \gdef\R{\mathbb{R}} \gdef\norm#1{\lVert #1 \rVert} ::: For $x \in \R^n$ we have $\norm{x} \ge 0$. ```` ## Directives Everything beyond markdown uses one syntax in three forms. | Form | Syntax | Use | |---|---|---| | Inline | `:name[content]` | a span of text | | Leaf | `::name` | a block with no body | | Container | `:::name` ... `:::` | a block with a body | Containers take an optional title and attributes on the opening line: ``` :::theorem[Rank–nullity] #rank-nullity .important key=value Body, written in normal Tern. ::: ``` | Attribute | Meaning | |---|---| | `[Title]` | the block's title; may contain inline markup | | `#id` | a label, for `@id` references and links | | `.class` | an extra CSS class | | `key=value`, `key="two words"` | becomes an HTML attribute, including `style` | Inline directives take attributes in braces after the brackets: `:aside[text]{#id .class}`. **Nesting.** Containers nest. With equal colon counts, each `:::` closes the innermost open block. To make deep nesting readable, give outer blocks more colons: ````demo ::::columns :::card Left ::: :::card Right ::: :::: ```` **Unknown names work.** A name Tern does not know becomes an element with that name as its class, so you can invent directives freely. The examples above defined a few labels, and this paragraph uses them: @thm-rank follows from @def-kernel, the sum is @eq-gauss, and the section on math is @math. | Target | How it gets an id | `@id` displays as | |---|---|---| | Environment | `:::theorem #thm-main` | "Theorem 1" | | Equation | `$$ ... $$ #eq-main` | "(1)" | | Heading | automatic from its text, or `## Title {#my-id}` | the heading's text | | Any other block or inline directive | `#id` in its attributes | the id | Heading ids are the lowercased title with punctuation removed and spaces turned into hyphens, so "Column widths" gets `column-widths`. Labels may contain letters, digits, `_`, `-` and `:`, so LaTeX-style names like `thm:main` work. ## Recall cards A question line starting with `??` followed by answer lines starting with `>>` makes a card whose answer is hidden until clicked. ````demo ?? When is a square matrix invertible? >> When its determinant is nonzero, >> equivalently when its kernel is trivial. ?? What is the derivative of $\sin x$? >> $$\cos x$$ ```` The answer may contain any Tern content, including display math. A `??` line with no `>>` after it is an ordinary paragraph. To hide a word inside a sentence, use `:hide[...]`. ## Layout ````demo :::columns widths="2 1" :::col **Main column.** `widths` gives one number per column, as proportions. Tern's own classes are prefixed `t-` (`t-block`, `t-head`, `t-card`, `t-eq`, and so on). ## How it works Understanding two details explains most surprises. 1. **The rest of the file is never parsed as HTML.** When the browser reaches the `tern.js` script tag, the script switches the browser's parser into plain-text mode for the remainder of the file. That is why `<`, `>` and `&` need no escaping, and why the script tag must be the first thing in the file and must load synchronously. 2. **The page rewrites itself.** Once loaded, Tern converts the source and replaces the document with the rendered result. "View source" shows your note; the browser's inspector shows the rendered page. ## Publishing A Tern note is an ordinary HTML file, so any static host serves it as a finished page. On GitHub Pages, enable Pages for the repository and push your notes together with `tern.js`. Add an empty `.nojekyll` file at the root so Pages serves files untouched. ## Editor support A Neovim plugin lives in the `nvim/` folder of the repository.
