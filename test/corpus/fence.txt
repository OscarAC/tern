# Fenced code and the raw HTML fence

Cases for the fence opener and its info string, the closing fence, verbatim and
dedented content, titled fences as numbered listings, the reserved keys, unclosed
fences inside prefix containers, and the ```` ```=html ```` door.

## fence/basic

spec: syntax-blocks#fence elements#output-contract

A backtick fence with a language: the content is verbatim and HTML-escaped, and the language becomes `language-LANG` on `<code>`.

````tern
```js
if (a < b && c) { go(); }
```
````

````json ast
{"type":"root","children":[{"type":"code","lang":"js","value":"if (a < b && c) { go(); }"}]}
````

````html
<pre data-t="code"><code class="language-js">if (a &lt; b &amp;&amp; c) { go(); }</code></pre>
````

## fence/untitled-attrs-on-pre

spec: syntax-blocks#fence syntax-blocks#positions syntax-blocks#merging-and-emission

The fenced-code example: an untitled fence puts author attributes on `<pre>`; `lines` wraps each line and `start` adds `data-start`, and neither is emitted as an attribute.

````tern
```python {start=10 lines .wide}
def take(it, n):
    return [x for _, x in zip(range(n), it)]
```
````

````html
<pre class="wide" data-t="code" data-lines data-start="10"><code class="language-python"><span class="t-line">def take(it, n):</span>
<span class="t-line">    return [x for _, x in zip(range(n), it)]</span></code></pre>
````

## fence/title-attrs-listing

spec: syntax-blocks#fence elements#output-contract elements#numbering

The titled-fence example: a titled fence is a numbered listing, `figure.t-block.code` with the id on the figure, the reserved keys on `<pre>`, and the label from the schema's `code` entry.

````tern
```js[A lazy Fibonacci generator]{#lst-fib lines hl=4}
function* fib() {
  let [a, b] = [0, 1];
  for (;;) {
    yield a;
    [a, b] = [b, a + b];
  }
}
```
````

````json ast
{"type":"root","children":[{"type":"code","lang":"js","attributes":{"id":"lst-fib"},"data":{"tern":{"title":[{"type":"text","value":"A lazy Fibonacci generator"}]}}}]}
````

````html
<figure id="lst-fib" class="t-block code" data-t="code"><pre data-lines data-hl="4"><code class="language-js"><span class="t-line">function* fib() {</span>
<span class="t-line">  let [a, b] = [0, 1];</span>
<span class="t-line">  for (;;) {</span>
<span class="t-line t-hl">    yield a;</span>
<span class="t-line">    [a, b] = [b, a + b];</span>
<span class="t-line">  }</span>
<span class="t-line">}</span></code></pre><figcaption class="t-title"><span class="t-label">Listing 1</span> A lazy Fibonacci generator</figcaption></figure>
````
