# Element mapping and output contract

How a name becomes an element, the allowlists, the output contract and the title
slots, with the reserved names and `schema.strict`. The fixture schema
is on unless a case says `schema=none`.

Names are case-sensitive everywhere (schema lookup, the
allowlists, the reserved list and the custom-element rule are all lower-case,
so `:::Aside` is an unknown name); the reserved list is checked before the
custom-element rule, and a reserved name falls back to `div` or `span`
without the reserved name as a class (`data-t` still names it); `name.unknown`
(only with `strict`) is for step-5 fallbacks alone.

## element/fallback-container-div

spec: syntax-blocks#r6 elements#names

A container name with no schema entry, no allowlist entry and no hyphen is a `div` carrying the name as its class (step 5).

````tern
:::idea[Key idea]{#k}
Body.
:::
````

````html
<div id="k" class="t-block idea" data-t="idea"><div class="t-title">Key idea</div><p>Body.</p></div>
````

## element/fallback-leaf-div

spec: syntax-blocks#r6 elements#names elements#output-contract

An unknown leaf name is a `div` with the name as its class and its bracket content inside.

````tern
::callout[Read *me*]
````

````html
<div class="callout" data-t="callout">Read <em>me</em></div>
````

## element/fallback-inline-span

spec: syntax-blocks#r6 elements#names elements#output-contract

An unknown inline name is a `span` with the name as its class.

````tern
An :idea[inline] one.
````

````html
<p>An <span class="idea" data-t="idea">inline</span> one.</p>
````

## element/schema-tag

spec: elements#names elements#title-slots

The schema entry's `tag` chooses the element (step 2): the fixture schema's `theorem` is a `<section>` with a counted label.

````tern
:::theorem[Rank–nullity]
If $V$ is finite-dimensional.
:::
````

````html
<section class="t-block theorem" data-t="theorem"><div class="t-title"><span class="t-label">Theorem 1</span> Rank–nullity</div><p>If <span class="t-math">V</span> is finite-dimensional.</p></section>
````

## element/schema-tag-absent-without-schema

spec: syntax-blocks#r6 elements#names
options: schema=none

Without a schema, `theorem` is just an unknown name: a `div`, no label, no number.

````tern
:::theorem[Rank–nullity]
Body.
:::
````

````html
<div class="t-block theorem" data-t="theorem"><div class="t-title">Rank–nullity</div><p>Body.</p></div>
````

## element/tag-override

spec: elements#names syntax-blocks#merging-and-emission

`{tag=x}` is step 1: the element becomes `x`, the key is consumed (never emitted) and recorded under `data.tern`.

````tern
:::box{tag=aside}
Aside text.
:::
````

````html
<aside class="t-block box" data-t="box"><p>Aside text.</p></aside>
````

````json transformed
{"children":[{"type":"containerDirective","name":"box","data":{"tern":{"tag":"aside"}}}]}
````

## element/tag-override-beats-schema

spec: elements#names

`{tag=…}` wins over the schema's `tag`; the schema still supplies the label and counter.

````tern
:::theorem{tag=article}
Body.
:::
````

````html
<article class="t-block theorem" data-t="theorem"><div class="t-title"><span class="t-label">Theorem 1</span></div><p>Body.</p></article>
````

## element/tag-on-reserved-or-core-name

spec: elements#reserved syntax-blocks#reserved syntax-blocks#r7

`tag=` cannot choose the element of a reserved name, which always falls back (`:::main` is a `div`), nor of a core block, which has its own output (`:::macros`). Rather than being ignored silently, it gets `attr.malformed` at the key, saying where it applies. A reserved value (`tag=main`) keeps its own `name.reserved` instead.

````tern
:::main{tag=section}
Body.
:::

:::macros{tag=div}
\newcommand{\R}{\mathbb{R}}
:::

:::main{tag=main}
Body.
:::
````
