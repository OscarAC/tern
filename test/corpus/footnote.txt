# Footnotes

Footnote definitions and references. Output follows the
README's footnote convention: the reference is `sup.t-fnref`, and the definitions are
collected after all content into `section.t-footnotes`, numbered by first reference,
with one `t-fnback` link (to the first reference) appended inside the definition's last
paragraph, or in a `<p>` of its own when the last block is not a paragraph; an unused
definition has none. Labels match case-insensitively; ids use the definition's
spelling.

## footnote/reference-basic

spec: syntax-inline#footnote-reference syntax-blocks#footnote-definition

The footnote-reference example: `[^LABEL]` becomes a numbered superscript link, and the definition is collected at the end.

````tern
Both are subspaces.[^subspace]

[^subspace]: Closed under addition.
````

````html
<p>Both are subspaces.<sup class="t-fnref"><a id="fnref-subspace" href="#fn-subspace">1</a></sup></p>
<section class="t-footnotes"><ol>
<li id="fn-subspace"><p>Closed under addition. <a class="t-fnback" href="#fnref-subspace">↩</a></p></li>
</ol></section>
````

{"type": "root", "children": [
  {"type": "paragraph", "children": [

    {"type": "footnoteReference", "identifier": "subspace"}

  {"type": "footnoteDefinition", "identifier": "subspace", "children": [
    {"type": "paragraph", "children": [{"type": "text", "value": "Closed under addition."}]}
  ]}

## footnote/def-continuation

spec: syntax-blocks#footnote-definition

The footnote-definition example: a line indented 2 columns continues the definition's paragraph, stripped by 2.

````tern

[^subspace]: Closed under addition and scaling: if $Tu = Tv = 0$
  then $T(u + \lambda v) = 0$.
````

````html
<p>See the kernel.<sup class="t-fnref"><a id="fnref-subspace" href="#fn-subspace">1</a></sup></p>
<section class="t-footnotes"><ol>
<li id="fn-subspace"><p>Closed under addition and scaling: if <span class="t-math">Tu = Tv = 0</span>
then <span class="t-math">T(u + \lambda v) = 0</span>. <a class="t-fnback" href="#fnref-subspace">↩</a></p></li>
</ol></section>
````

## footnote/duplicate

spec: syntax-blocks#footnote-definition elements#ids

A second definition of the same label is warned about at that definition, and the first one wins. The losing definition is dropped: its content is not emitted, it generates no `fn-` id, and `footnote.duplicate` is reported on the second definition only, with no `id.duplicate`.

````tern
Text.[^a]

[^a]: First definition.
[^a]: Second definition.
````

````html
<p>Text.<sup class="t-fnref"><a id="fnref-a" href="#fn-a">1</a></sup></p>
<section class="t-footnotes"><ol>
<li id="fn-a"><p>First definition. <a class="t-fnback" href="#fnref-a">↩</a></p></li>
</ol></section>
````

4:1 warning footnote.duplicate
