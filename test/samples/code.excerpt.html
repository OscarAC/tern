Notes on iterators

Listing 1 yields forever; take what you need with take(fib(), 10).

Inline code keeps every character: a pipeline ls -l | sort -k5, a comparison a < b && c > d, a backtick `, a span that contains one a`b, a closing tag </script> and a generic Vec<T>. Outside code, Vec<T> and List<int> are text as typed.

def take(it, n):
    return [x for _, x in zip(range(n), it)]

Escapes

A literal asterisk *, an underscore in snake_case (no escape needed), a price of $5 (no escape needed either) and a pair of dollars $x$ that must not become maths, a colon before a bracket :kbd[x], an at-sign @handle, and brackets [not a span]{.x}. Backslash itself: \. Some_file_name.txt and 2 * 3 * 4 need nothing.
