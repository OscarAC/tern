Tip Counts go first

Any motion takes a count: 3dd, 5j. The count comes first, not last.

Warning

:q! discards changes. Prefer :x (write if changed, then quit).

Pipes and backticks in code

A shell filter in a sentence: sort | uniq -c. A backtick itself: `, and a span that contains one: a`b. In a table cell `a|b` and |x| keep their pipes; a literal pipe anywhere else is \|, and a backtick inside … is \`.
